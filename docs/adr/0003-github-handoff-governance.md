# ADR-0003: GitHubを正本とする引き継ぎ・証拠管理

- 日付: 2026-11-09
- 状態: 提案（本PRのレビュー対象）。GitHub正本/月額0円/マージ・本番承認はユーザー指示。新技術の承認ではない。
- 関連: BR-004、NFR-001/007/010/012、OQ-010/011

## 背景

mainは文書のみ、#3は#2を包含するPoCで、旧作業手順が残り現在地が分かりにくい。チャットだけではCloudの新セッションから検証範囲を再現できない。

## 提案

GitHubの要件/ADR/Issue/PR/CIとhandoffを一続きにする。文書PRは#3に積み、実装修正は独立PRにする。採用技術はADR-0001/0002の範囲を継続し、新規有料サービス、DB/フレームワーク、公開構成を今回導入しない。履歴・未承認OQを保持し、要件承認と実装の検証を分ける。

## 代替案

- チャットのみ: 低負荷だが監査・別セッション再開が弱い。
- 別の管理SaaS: 転記と費用/権限管理が増える。今は不要。
- まず#2だけ統合: 二段階レビューになる。#3が履歴を包含するため、#3を修正して統合する案を推奨。

## 影響と採用条件

[運用/学習案](../DEVELOPMENT_WORKFLOW.md)と[監査](../audit/2026-11-09.md)をレビューする。mainマージ・本番デプロイはユーザー承認、要件v1.0は別の明示承認を必要とする。CI設定変更やブランチ保護の適用、クラウド公開を行った記録ではない。

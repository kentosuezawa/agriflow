# ADR-0002: Phase 2は既存Nodeアプリを段階的に改善する設計

- 日付: 2026-11-05
- 状態: 設計案を採用。新画面の実装は未着手。
- 関連: BR-002/003/004、FR-001〜018、NFR-002/003/005/006

既存のNode HTTPサーバー・ブラウザUI・JSON保存を再利用する。
次の実装でUIをTypeScriptモジュールへ段階的に移す案とし、React/Next.jsやDBの導入は今は決めない。
小規模な単一利用者のPoCでは、既存の動く構成を維持するほうが重複実装と運用依存を抑えられる。
TypeScriptの型をサーバー・計算境界で共有できる。月額サービス、クラウド、認証サービスは追加しない。

React/Next.jsは画面の状態管理が複雑化した際の候補、SQLiteは履歴のトランザクション・検索が必要になった際の候補。
PostgreSQL/FastAPIは現段階で複数利用者・別言語APIが不要なため採用を保留する。
現行JSON保存は単一プロセス専用であり、多人数編集・大容量履歴の保証はしない。

Phase 1測定では探索が約2秒で打ち切られた。将来のWeb設計では計算をworker threadへ移し、
入力版・ジョブ状態・結果を紐づける。同期の既存APIを本番向け完了形とはしない。
公開デモの認証・書込保護は未決定のためデプロイしない。
詳細は[Web基本設計](../design/PHASE2_WEB.md)。
